# Data

`sources/*.json` is the only thing edited by hand. Everything else here is
generated by `python scripts/build.py` and should not be edited directly.

| File | What it is |
|---|---|
| `sources/*.json` | The hand-maintained dataset, split by category |
| `programs.json` | Merged, validated, sorted by deadline |
| `programs.csv` | Flat export for Notion, Sheets or Excel |
| `deadlines.ics` | Calendar feed, deadlines and opening dates, with 14-day and 3-day reminders |
| `watch-state.json` | Content hashes from the last watcher run |
| `watch-report.md` | Human-readable report from the last watcher run |

The build refuses to emit a dataset containing bad dates, unknown enum values,
duplicate ids, relative URLs, or a `confirmed` deadline status with no deadline.
